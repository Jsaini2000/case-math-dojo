# Case Math Dojo

A mental math trainer for consulting case interviews. It drills millions, billions and percentages instead of times tables.

## Modes
- **Sprint**: a timed run. Consecutive correct answers raise a score multiplier and fast answers earn bonus points.
- **Case Run**: a chained 5–6 step mini-case (market sizing, profitability, product launch, M&A). Each answer feeds the next step.
- **Practice**: untimed, with the shortcut explained after every question.
- **Daily Challenge**: the same 12 questions for everyone each day.
- **Fix My Weak Spots**: targets your 3 lowest-accuracy topics.

## Topics
Big multiplication and division, % of, what %, % change, fractions → %, margins and profit, breakeven, and growth (compounding, rule of 72, reversing a % change).

Answers accept shorthand like `2.4M`, `450k`, `1.2bn` and `15%`. If your digits are right but the zeros are off, the game flags it as a magnitude error.

## Run it
It's a single `index.html` with no build step. Open it in a browser, or use the hosted version on GitHub Pages. Progress is saved in your browser's localStorage.
